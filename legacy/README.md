# Prototipo antiguo (obsoleto)

Estos archivos se conservan solo como referencia histórica:

- `config.h`: configuración del prototipo dwm 6.5, no la plantilla actual.
- `dwm.desktop`: sesión antigua de LightDM.
- `build-dwm.sh`, `build-eww.sh`, `install-deps.sh`: scripts del prototipo.
- `patches/`: parches usados durante la exploración.
- `src/dwm-*`: fuentes/paquetes de dwm 6.5 del prototipo.

**No usar nada de aquí en la instalación.** La fuente de verdad es:

```text
install.sh
lib/
templates/
bin/
assets/
src/chadwm/chadwm
src/eww
```

Ver `README.md`, `PROGRESS.md`, `AGENTS.md` y `DECISIONS.md`.
